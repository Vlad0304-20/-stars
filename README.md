# -stars
Решение задачи по инфохимии от МИФИ, от команды stars

Прогнозирование индекса селективности молекул против вируса оспы (VACV)



//Скрипт выгрузки данных

Для расширения обучающей выборки создан скрипт автоматического сбора данных `data_mining.py`
Источником данных является международная открывая база данных по хемоинформатике ChEMBL 
Скрипт через `new_client.assay.search` находит все идентификаторы лабораторных экспериментов, в описании которых упоминается вирус оспы.
Из найденных тестов пачками по 500 штук выкачиваются только численные показатели полумаксимальной концентрации ингибирования `IC50` и полумаксимальной концентрации цитотоксичности `CC50`.
По системным ID документов ChEMBL подтягиваются официальные цифровые паспорта научных статей `doi_работа` для обеспечения прозрачности происхождения данных.
Для каждой участвующей молекулы скачивается её текстовое химическое представление `SMILES`.
Рассчитывается индекс селективности.
Из итоговой таблицы удаляются `dropna` все записи, у которых отсутствует формула SMILES или для которых невозможно вычислить индекс SI из-за отсутствия парных замеров.
